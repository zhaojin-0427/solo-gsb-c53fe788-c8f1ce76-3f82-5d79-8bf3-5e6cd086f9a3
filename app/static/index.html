🎲 多人公平抽签室

承诺-揭示（commit-reveal）+ 全员秘密派生种子的公平抽签。轮次不可变、超时作废、全程可审计复算。

主持人 · 创建轮次 成员 · 凭邀请码加入 独立审计复算

创建不可变轮次

创建后成员顺序、奖项与两个截止时间均不可更改。请把生成的一次性邀请码分别发给对应成员。

提示：创建后请保存主持人链接，它是管理与导出审计的唯一凭证。

凭一次性邀请码加入

邀请码只能使用一次：首次加入会换发本设备的会话令牌。请始终在同一设备/浏览器完成承诺与揭示。

它如何保证公平？

  1. 成员各自在浏览器本地生成随机秘密，只公开 SHA-256(嵌套长度前缀编码(轮次‖位次‖姓名‖秘密)) 承诺。
  2. 全员承诺到齐后才进入揭示阶段；提前揭示、超时、承诺与秘密不符 → 整轮作废。
  3. 服务端对“配置（含固定成员顺序、奖项、截止时间）+ 按顺序排列的全部秘密”求 SHA-256 种子，任一字节被篡改都会改变结果。
  4. 用 HMAC-SHA256 + 拒绝采样在 [0,i] 上做无模偏差的 Fisher-Yates；拒绝轨迹随结果一起导出。
  5. 阶段切换/结算均在带版本号的数据库事务内原子完成；导出的审计 JSON 可在“独立审计复算”页离线复算。
